# 📝 Beautiful To-Do List App
A delightful, pastel-themed todo list application inspired by aesthetic planner designs. This app combines functionality with beautiful design to help you stay organized and productive.

### Prerequisites
- Any modern web browser (Chrome, Firefox, Safari, Edge)
- No installation required!

### Setup
1. **Download all files** to a folder:
   - `index.html`
   - `style.css` 
   - `script.js`

2. **Open the app**:
   - Double-click `index.html` to open in your browser
   - Or right-click → "Open with" → your preferred browser

## 📖 How to Use Each Section
### 📋 **To Do List** (Pink Section)
**Purpose**: Your main task management area
### 📝 **Notes** (Peach Section)  
**Purpose**: Free-form writing space
### 🎯 **Focus** (Blue Section)
**Purpose**: Your top 3 priorities for the day
### 💡 **Remember** (Teal Section)
**Purpose**: Important information to keep handy
